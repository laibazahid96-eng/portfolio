LAIBA ZAHID - AI ENGINEER PORTFOLIO
=====================================

This is a simple, beginner-friendly static portfolio website.

FOLDER STRUCTURE
----------------
Laiba_Zahid_AI_Engineer_Portfolio/
|
|-- index.html
|-- README.txt
|-- css/
|   `-- style.css
|-- js/
|   `-- script.js
`-- assets/
    |-- Laiba_Zahid_CV.pdf
    `-- images/
        `-- laiba-zahid-profile.jpeg

HOW TO RUN
----------
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser.
   OR
4. Install the VS Code Live Server extension and click "Go Live".

EDITING
-------
- Personal text: index.html
- Design/colors/layout: css/style.css
- Typing animation/contact behavior: js/script.js
- Profile picture: assets/images/laiba-zahid-profile.jpeg
- CV: assets/Laiba_Zahid_CV.pdf
- Project GitHub links: index.html

NOTES
-----
- The website is a custom implementation inspired by the supplied Simone dark
  portfolio reference, not a copy of the template's source code.
- The testimonial section and statistics bar were intentionally removed.
- The contact form uses mailto, so it opens the visitor's email application.
- No backend is required for this version.
- Project descriptions are editable placeholders based on the project names and
  the AI focus supplied by the owner. Update them after reviewing each project.
